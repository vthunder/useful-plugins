When a question can be answered by retrieving a single zettel, no new knowledge was created — the answer was already captured. But when answering requires combining multiple zettels in a way not represented in any of them individually, the synthesis itself is new knowledge.

This has a practical implication for knowledge systems: every query is an opportunity to detect and capture emergent understanding. After answering a question that required non-obvious synthesis, ask: "Is this combined insight captured anywhere?" If not, it warrants a new zettel linking back to all the sources it drew from.

This is especially valuable for release-spec libraries, where Q&A can surface implicit design decisions that were assumed but never made explicit — a gap that's invisible until someone asks the right question.

The corollary: a knowledge base that is only ever written to (never queried) misses the compounding effect. Querying is not just retrieval — it's a mechanism for discovering what the network of zettels implies but hasn't stated.
