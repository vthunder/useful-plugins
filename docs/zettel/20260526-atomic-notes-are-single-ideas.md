A zettel is a markdown file containing exactly one idea, claim, or named concept. "Exactly one" is the operative constraint: if removing a paragraph doesn't break the zettel's argument, the paragraph belongs in a different zettel or nowhere.

Atomicity enables reuse. A note about a single concept can be linked from any other zettel that touches that concept, regardless of domain. A composite note — say, "memory and learning" — can only be linked from notes about both memory and learning together, which sharply limits its connectivity.

The title enforces the constraint: it must state a claim or name a concept precisely enough that a reader knows what the zettel is and is not about. Category titles ("Memory notes", "ACT-R research") fail this test. Claim titles ("Working memory capacity is 4±1 chunks") pass it.

The payoff is a knowledge graph where each node has a clear identity and every link is meaningful rather than approximate.
